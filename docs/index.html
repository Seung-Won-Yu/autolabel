작동 방식

라벨링할수록
라벨링이 쉬워진다

사람이 승인한 라벨이 다음 라운드의 교사가 된다. 이 고리가 도구의 심장이다.

1

투입 — 복사 없이 연결까지

이미지 업로드, 기존 폴더 연결(복사 없음, 기존 COCO·YOLO 라벨 흡수), 또는 비디오 임포트.

비디오는 프레임 추출 + 메모리 전파 트래킹으로 프레임별 초안까지 자동
2

자동 초안 — 엔진은 알아서 고른다

전용 모델이 있으면 그것, 없으면 SAM 3, 그것도 없으면 Grounding DINO + SAM. 고해상도·작은 객체는 타일링으로 나눠 본다.

장당 0.8초(박스) · 프롬프트가 약하면 실험 기능이 후보를 비교해 준다
3

문맥 심판 — 기준으로 판정

“사고에 연루된 차량만” 같은 판정은 검출 모델이 못 푼다. 기준문을 읽는 VLM이 박스마다 근거를 달아 예비 판정한다.

같은 기준 재실행은 캐시로 비용 0 · 24px 미만 박스는 묻지 않고 보류
4

리뷰 — 예외 확인

위반·불확실·저신뢰 순으로 정렬해 보여준다. 고신뢰 이미지는 미리보기를 확인하고 한 번에 승인.

통계적 배치 검수로 전수 대신 필요한 만큼만 검사
5

자동 학습 — 이겨야 교체

승인 8장부터 별도 프로세스로 학습(서버 재시작에도 생존). 3분할 + 고정 홀드아웃으로 라운드마다 같은 기준으로 평가한다.

데이터 규모에 따라 n → s → m 자동 승급 · 이전 모델로 롤백 가능

솔직한 답

자주 나오는 질문

정말 무료인가?

도구와 로컬 모델(SAM 3 · Grounding DINO · SAM · YOLO)은 전부 로컬 실행이라 사용료가 없다. 문맥 심판도 Claude Code CLI가 설치돼 있으면 구독에 포함된 경로로 돌아 별도 과금이 없다.

다만 구독 사용량은 소비된다. 완전 무료를 원하면 로컬 Ollama 비전 모델로 바꿀 수 있다 (품질은 낮아진다). ANTHROPIC_API_KEY를 넣는 순간부터만 종량 과금이다.

사람이 아예 안 봐도 되나?

아니다. 그리고 그건 어떤 도구도 못 한다 — 라벨의 정답 자체가 프로젝트마다 다르게 정의되기 때문이다(“접시는 bowl인가?”는 모델이 아니라 사람이 정한다).

이 도구가 겨냥하는 최선은 전수 판독을 예외 확인으로 줄이는 것이다. 기준을 글로 적어두면 그 판단을 기계가 먼저 대신하고, 사람은 위반·불확실만 본다.

내 도메인은 특수한데 될까?

텍스트로 설명되는 개념이면 첫날부터 자동에 가깝다(서명 실측 0.995). PCB 미세 결함처럼 제로샷이 완전히 실패하는 도메인은 수동 수십 장이 필요하다 — 대신 그 뒤로는 급격히 좋아진다(42장 0.593 → 300장 0.963).

어느 쪽인지는 첫 배치 결과가 알려준다. 검출률이 낮으면 도구가 다음 수(프롬프트 실험 / 직접 라벨 후 학습)를 지정해 준다.

팀에서 같이 쓸 수 있나?

지금은 1인 로컬 전제다(SQLite · 단일 프로세스). 여러 사람이 동시에 쓰려면 잡 큐와 DB 교체가 필요하고, 그건 로드맵에 남아 있다.

라이선스는?

전용 모델 학습에 쓰는 YOLO 계열은 AGPL-3.0이다. 개인·내부 사용은 무방하지만 제품에 실어 배포할 계획이면 교체가 필요하다 — 교체 지점은 server/train_worker.py 한 곳으로 격리해 두었다.

SAM 3는 Meta의 자체 라이선스(SAM License)를 따른다. 상용·재배포 조건은 원문을 확인할 것.
