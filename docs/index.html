사람은 리뷰만 한다

기존 도구는 사람이 그리는 화면에 오토라벨을 곁들인다. 이 도구는 순서를 뒤집어, 모델이 먼저 깔고 사람이 예외만 확인하는 흐름을 기본으로 만들었다.

  1. 1투입 — 이미지 업로드 · 폴더 연결(복사 없음) · 비디오 임포트
  2. 2클래스 정의 — 찾을 것을 이름과 프롬프트로 적는다
  3. 3자동 초안 — 전용 모델 → SAM 3 → Grounding DINO 순으로 알아서 라우팅
  4. 4문맥 심판 — 판정 기준을 글로 쓰면 박스마다 ✓ / ✗ / ? + 근거
  5. 5리뷰 — 위반·불확실·저신뢰만 확인. 고신뢰는 자동 승인
  6. 6자동 학습 — 승인이 쌓이면 전용 모델 학습, 게이트를 이기면 3번 엔진 교체
  7. 7익스포트 — COCO / YOLO zip · 학습된 .pt · Colab 노트북

6 → 3으로 돌아가는 고리 = 라벨링할수록 라벨링이 쉬워진다

세 가지가 다르다

제로샷이 첫날부터

SAM 3가 텍스트 한 구절로 모든 인스턴스를 찾는다. 문서 서명 도메인에서 기존 경로 mAP50 0.000 → 0.995 — 시드 라벨링 비용이 사실상 사라진다.

기준으로 판정한다

“사고에 연루된 차량만” 같은 문맥 판정은 검출 모델이 못 푼다. 기준문을 읽는 VLM이 박스마다 근거를 달아 예비 판정하고, 사람은 예외만 본다.

쓸수록 좋아진다

승인 라벨로 전용 모델을 자동 학습하고, 홀드아웃에서 기존 모델을 이길 때만 교체한다. 지면 조용히 폐기 — 재학습이 품질을 떨어뜨리지 않는다.

시작하기

Apple Silicon Mac + Python 3.11 + Node 20 기준. 세 줄이면 끝난다.

# 1. 최초 1회 — venv · 의존성 · SAM 가중치 · 브라우저 디코더
./setup.sh

# 2. 실행 — 백엔드 + 프론트 동시, 브라우저 자동 오픈
./start.sh

# 3. 코드를 고쳤으면 (백엔드 49개 · 브라우저 26개)
./test.sh && ./test-e2e.sh
  • SAM 3는 선택 — facebook/sam3 접근 승인 후 models/sam3.pt로 두면 제로샷이 자동 승급된다. 없으면 Grounding DINO + SAM 경로로 동작.
  • 문맥 심판도 선택 — Claude Code CLI가 있으면 구독으로 무료 사용, ANTHROPIC_API_KEY가 있으면 API, 로컬 Ollama도 가능. 없으면 그 기능만 비활성.
  • 1인 로컬 전제 — SQLite + 단일 프로세스. 팀·수십만 장 규모는 큐와 DB 교체가 필요하다.
  • 라이선스 주의 — 전용 모델이 쓰는 YOLO 계열은 AGPL-3.0. 개인·내부 사용은 무방, 배포 시 교체 지점은 server/train_worker.py.
