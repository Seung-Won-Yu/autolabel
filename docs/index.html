작동 방식

라벨링할수록
라벨링이 쉬워진다

사람이 승인한 라벨이 다음 라운드의 교사가 된다. 이 고리가 도구의 심장이다.

1

투입 — 복사 없이 연결까지

이미지 업로드, 기존 폴더 연결(복사 없음, 기존 COCO·YOLO 라벨 흡수), 또는 비디오 임포트.

비디오는 프레임 추출 + 메모리 전파 트래킹으로 프레임별 초안까지 자동
2

자동 초안 — 두 엔진을 먼저 견준다

전용 모델이 없으면 SAM 3와 Grounding DINO를 앞 30장 교차 실행해 비교 표본을 만든다. 승인 정답이 쌓이면 클래스마다 검수 비용이 적었던 엔진 또는 둘의 합의를 자동 선택한다.

경로가 정해진 뒤에도 10장에 1장은 두 엔진을 다시 돌려 근거를 갱신 · SAM 3가 없으면 Grounding DINO(+SAM 마스크)
3

문맥 심판 — 기준으로 판정

“사고에 연루된 차량만” 같은 판정은 검출 모델이 못 푼다. 기준문을 읽는 VLM이 박스마다 근거를 달아 예비 판정한다.

같은 기준 재실행은 캐시로 비용 0 · 24px 미만 박스는 묻지 않고 보류
4

리뷰 — 예외 확인

위반·불확실·저신뢰 순으로 정렬해 보여준다. 고신뢰 이미지는 미리보기를 확인하고 한 번에 승인.

통계적 배치 검수로 전수 대신 필요한 만큼만 검사
5

자동 학습 — 이겨야 교체

승인 8장부터 실험 학습을 시작하고, 데이터가 쌓이면 그룹이 섞이지 않는 train/val/test로 평가한다. 현재 모델과 같은 val에서 비교해 이긴 후보만 교체한다.

학습 중 epoch·ETA 표시 · Colab 번들도 성능표를 검증한 뒤 적용
↻

거짓 확신 대신 “모른다” — 사람 확인 대상

  • 비용 — Claude Code CLI가 있으면 구독 경로로 무료, API 키가 있으면 Claude API, 로컬 Ollama도 가능. 셋 다 없으면 이 기능만 비활성되고 나머지는 정상 동작한다.
  • 재실행이 공짜 — 판정은 기준 해시와 박스 스냅샷을 키로 캐시된다. 고친 박스만 다시 묻는다.
  • 중단에 안전 — 서버를 세 번 강제 재시작한 실측에서 “중단됨”을 정직하게 보고하고, 재실행 시 캐시 재사용으로 판정 유실 0.

시작하기

세 단계면 시작된다

Apple Silicon Mac · Python 3.11 · Node 20 기준.

# 1. 저장소 받기
git clone https://github.com/Seung-Won-Yu/autolabel.git && cd autolabel

# 2. 최초 1회 — venv · 의존성 · SAM 가중치 · 브라우저 디코더
./setup.sh

# 3. 실행 — 백엔드 + 프론트 동시, 브라우저 자동 오픈
./start.sh
  • 코드를 고쳤다면 — ./test.sh && ./test-e2e.sh로 백엔드 88개와 프론트 49개(unit 14 + 브라우저 35) 회귀 경로를 확인한다.
  • 첫 프로젝트 — 이름 짓고, 클래스 한 줄 적고, 이미지 던지고, “전체 오토라벨”을 누른다. 나머지는 “지금 할 일” 배너가 단계별로 안내한다.
  • SAM 3는 선택 — facebook/sam3 접근 승인 후 models/sam3.pt로 두면 제로샷이 자동 승급된다. 없으면 Grounding DINO + SAM 경로로 동작.
  • 결과는 어디로든 — COCO / YOLO zip은 바로 학습 가능한 구조, 학습된 .pt도 내려받는다. 로컬로 감당 안 되는 규모는 Colab 노트북으로.
솔직한 답

자주 나오는 질문

정말 무료인가?

도구와 로컬 모델(SAM 3 · Grounding DINO · SAM · YOLO)은 전부 로컬 실행이라 사용료가 없다. 문맥 심판도 Claude Code CLI가 설치돼 있으면 구독에 포함된 경로로 돌아 별도 과금이 없다.

다만 구독 사용량은 소비된다. 완전 무료를 원하면 로컬 Ollama 비전 모델로 바꿀 수 있다 (품질은 낮아진다). ANTHROPIC_API_KEY를 넣는 순간부터만 종량 과금이다.

사람이 아예 안 봐도 되나?

아니다. 그리고 그건 어떤 도구도 못 한다 — 라벨의 정답 자체가 프로젝트마다 다르게 정의되기 때문이다(“접시는 bowl인가?”는 모델이 아니라 사람이 정한다).

이 도구가 겨냥하는 최선은 전수 판독을 예외 확인으로 줄이는 것이다. 기준을 글로 적어두면 그 판단을 기계가 먼저 대신하고, 사람은 위반·불확실만 본다.

내 도메인은 특수한데 될까?

텍스트로 설명되는 개념이면 첫날부터 자동에 가깝다(서명 실측 0.995). PCB 미세 결함처럼 제로샷이 완전히 실패하는 도메인은 수동 수십 장이 필요하다 — 대신 그 뒤로는 급격히 좋아진다(42장 0.571 → 300장 0.963).

첫 3장에서는 SAM 3와 Grounding DINO를 함께 돌려 합의·단독 후보를 보여주고, 사람이 승인한 결과로 클래스별 엔진을 보정한다. 그래도 검출률이 낮으면 도구가 다음 수 (프롬프트 실험 / 직접 라벨 후 학습)를 지정한다.

팀에서 같이 쓸 수 있나?

지금은 1인 로컬 전제다(SQLite · 단일 프로세스). 여러 사람이 동시에 쓰려면 잡 큐와 DB 교체가 필요하고, 그건 로드맵에 남아 있다.

라이선스는?

전용 모델 학습에 쓰는 YOLO 계열은 AGPL-3.0이다. 개인·내부 사용은 무방하지만 제품에 실어 배포할 계획이면 교체가 필요하다 — 교체 지점은 server/train_worker.py 한 곳으로 격리해 두었다.

SAM 3는 Meta의 자체 라이선스(SAM License)를 따른다. 상용·재배포 조건은 원문을 확인할 것.
