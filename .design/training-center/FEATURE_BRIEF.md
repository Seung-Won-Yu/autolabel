# 학습센터 기능 브리프

## 사용자와 문제

- 대상: 개인 데이터로 오토라벨 모델을 만들고 반복 개선하는 사용자
- 핵심 작업: 승인 라벨이 학습 가능한지 확인하고, 학습이 오래 걸려도 현재 단계와 남은 시간을 이해하며, 새 모델이 실제로 적용됐는지 판단한다.
- 현재 문제: 장시간 `학습 중`만 보여 멈춤 여부를 알 수 없고, 학습 기능이 설정 패널 안에 숨어 있으며, 완료 후에도 새 모델 승격/기존 모델 유지 이유가 즉시 읽히지 않는다.

## 제품 흐름

1. 데이터 준비: 승인 장수, 예상 train/val/test 분할, 다음 자동 학습 조건을 확인한다.
2. 모델 학습: epoch `현재/전체`, 진행률, 경과 시간, 예상 남은 시간을 본다.
3. 성능 검증: validation과 완전 분리된 holdout test 진행을 구분해 본다.
4. 기존 모델 비교: challenger와 현재 champion을 같은 validation으로 비교한다.
5. 적용 결정: 새 모델 적용 또는 기존 모델 유지 결과와 핵심 지표를 확인한다.

## 화면 상태

- 준비: 접힌 한 줄 요약을 기본으로 하되 첫 모델이 없으면 준비도를 강조한다.
- 실행 중: 자동으로 펼치고 단계 표시, epoch 진행률, ETA를 `aria-live`로 갱신한다.
- 완료: 적용 여부, validation mAP50, holdout mAP50, 운영 F1, 선택 checkpoint를 설명한다.
- 실패: 실패 단계와 원인을 보여주고 같은 위치에서 재시도할 수 있게 한다.
- Colab: 로컬 학습과 동일한 학습센터 안에서 대안 경로로 제공한다.

## 완료 기준

- 학습센터는 설정 패널을 접어도 항상 접근 가능하다.
- 백엔드가 실제 epoch 종료 이벤트마다 상태 파일에 epoch/진행률/경과/ETA를 쓴다.
- 프론트는 실행 중 1초 간격, 대기 중 5초 간격으로 상태를 갱신한다.
- 학습 전 승인 장수와 예상 split, 추천 모델, 다음 자동 학습 시점을 보여준다.
- 완료 후 새 모델이 적용됐는지 기존 모델이 유지됐는지 한 문장으로 구분한다.
- 데스크톱과 모바일에서 주요 동작이 보이고 키보드/스크린리더 상태 전달이 가능하다.
