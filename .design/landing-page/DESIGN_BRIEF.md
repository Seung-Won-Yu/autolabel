# autolabel landing page brief

## Outcome

Apple Silicon에서 비전 데이터셋을 만드는 1인 개발자·ML 실무자가 첫 화면에서
`모델 초안 → 예외 검수 → 자동 학습`의 차이를 이해하고, 근거 수치를 확인한 뒤
설치 또는 GitHub 저장소로 이동할 수 있는 공개 랜딩페이지를 만든다.

## Scope

- 공개 진입점 `docs/index.html`의 정보 구조, 카피, 비주얼, 반응형, 접근성, SEO
- 정적 HTML 한 파일 중심과 외부 런타임 의존 0 유지
- 실제 앱 UI, 백엔드, 측정 수치와 설치 절차는 변경하지 않음
- 소셜 공유용 정적 OG 이미지 추가

## Experience

1. 첫 화면: 무엇을 자동화하는지, 로컬 우선인지, 실제 근거가 있는지 확인
2. 문제와 제품 루프: 사람이 전부 그리는 방식과 예외 검수 방식 비교
3. 신뢰: 문맥 심판, 실측 수치, 실패를 숨기지 않는 설계 원칙 확인
4. 행동: 3단계 설치 확인 후 GitHub로 이동

## Direction

- 실제 앱의 역할색(파랑=작업, 초록=통과, 빨강=위반, 노랑=불확실)을 사용
- 장식용 글로우 대신 좌표 그리드와 검출 박스를 연상시키는 정밀한 배경
- 사실 수치는 애니메이션으로 왜곡하지 않고 즉시 최종값 노출
- 데스크톱과 모바일 모두 첫 CTA, 내비게이션, 앱 도식이 읽히도록 구성

## Done criteria

- 1440px, 390px에서 가로 오버플로 없음
- 내부 앵커 전부 유효, 비교 슬라이더 키보드 조작 가능
- 포커스 표시, skip link, landmark, reduced motion 지원
- 콘솔 오류 0, 모든 리빌 요소 정상 노출
- 다크·라이트 테마 렌더 확인, OG 이미지 1200×630 생성
