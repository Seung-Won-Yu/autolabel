# 전체 라벨링 파이프라인 개선 브리프

## 사용자와 과업

- 사용자: 개인 또는 소규모 팀에서 도메인 이미지 데이터셋을 만드는 ML 실무자
- 핵심 과업: 이미지 입력부터 모델 초안, 사람 검수, 승인 데이터 학습, 품질 확인,
  COCO/YOLO 반출까지 라벨 오염 없이 한 흐름으로 끝낸다
- 성공 신호: 사용자가 현재 단계와 다음 행동을 화면에서 이해하고, 학습·검수에
  들어간 이미지가 정확히 무엇인지 재현할 수 있다

## 범위

1. 로컬 오토라벨·리뷰·승인·QA·익스포트 종단 흐름
2. 승인 데이터 패키지 → Colab 학습 → `best.pt` 재등록 흐름
3. 통계 검수 표본 선택과 이미지별 정상/오류 판정 흐름
4. 데스크톱과 좁은 창의 작업 가능성, 상태 피드백, 키보드·모달 기본 접근성

## 비범위

- Colab 세션을 앱에서 원격 제어하거나 Google 계정을 연동하는 기능
- 모델 아키텍처 교체 또는 새 외부 서비스 도입
- 모바일에서 데스크톱과 동일한 고밀도 박스 편집 경험 보장

## 완료 기준

- Colab용 zip에는 승인 이미지만 있고 train/val/test가 겹치지 않는다
- Colab 노트북은 test 홀드아웃으로 최종 평가하고 입력 파라미터를 검증한다
- 통계 검수 중에는 표본 이미지만 보이며 전부 정상/오류 판정해야 제출할 수 있다
- 앱의 언어·제목·포커스·상태 알림이 실제 한국어 작업 앱과 일치한다
- 1440px와 768px에서 핵심 작업 흐름이 가능하고 390px에서는 안내 가능한 레이아웃이다
- 백엔드, 프런트 단위, Playwright, 실제 종단 QA가 통과한다
