# autolabel

**모델이 먼저 라벨을 만들고, 사람은 예외만 고친다.**

이미지 폴더를 넣고 객체를 *말하거나 · 예시로 그리거나 · 클릭*하면 초안이 만들어진다.

## 왜 다른가

기존 라벨링 도구는 "사람이 그리는 화면"이고 오토라벨은 부가 기능이다.
이 도구는 반대로 **모델이 먼저 다 깔고 사람은 틀린 것만 고치는 흐름**을 1급 시민으로 만들었다.
그래서 라벨링을 할수록 초안이 좋아지고, 초안이 좋아지면 리뷰가 줄어든다.

```
 ┌──────────────────────────────────────────────────────────────┐
 │  텍스트 프롬프트  ·  예시 박스 1개  ·  SAM 클릭  ·  비디오   │
 └───────────────────────────┬──────────────────────────────────┘
                             ▼
                   자동 초안 (배치 / 단건)
                             ▼
        문맥 심판 — 기준문으로 박스마다 ✓ / ✗ / ?  + 근거
                             ▼
          리뷰 큐  ─ 위반·불확실·저신뢰 우선 정렬
                             ▼
              승인 8장 → 전용 모델 자동 학습
                             ▼
        게이트 통과 시 오토라벨 엔진 교체 ──┐
                             ▲             │
                             └─────────────┘
                       라벨링할수록 라벨링이 쉬워진다
```

**엔진 라우팅** — 활성 전용 모델을 우선 사용한다. 전용 모델이 없으면 SAM 3와
Grounding DINO를 처음 3장에서 교차 시험하고, 사람이 승인한 결과가 쌓이면
클래스별로 검수 비용이 적었던 엔진을 자동 선택한다. SAM 3가 없으면 Grounding DINO(+SAM 마스크)로 동작한다.

## 60초 시작

기준 환경은 Apple Silicon Mac · Python 3.11 · Node 20. 최초 셋업에서 SAM 가중치 1.2GB와 프론트 의존성을 내려받는다.

```bash
git clone https://github.com/Seung-Won-Yu/autolabel.git && cd autolabel
./setup.sh     # 최초 1회: venv + 의존성 + SAM 가중치(1.2GB) + 브라우저 디코더
./start.sh     # 백엔드 + 프론트 동시 실행, 브라우저 자동 오픈 (종료: Ctrl+C)
```

브라우저가 열리면:

1. 프로젝트 생성 → 클래스 정의 (이름 / 검출 프롬프트 / 임계값)
2. 이미지 업로드(드래그앤드롭) 또는 **기존 폴더 연결**(복사 없음) → **전체 오토라벨**
3. 리뷰: `←→` 이동 · `A` 승인 · `X` 거부 · `Del` 삭제 · `?` 단축키
4. 보정: `B` 박스 · `M` SAM 클릭 · `E` 예시 찾기 · `⌘Z` 되돌리기(이미지 건너서도)
5. 승인이 쌓이면 전용 모델이 자동 학습 → 오토라벨 품질 상승
6. `QA 분석`으로 추천 임계값 확인 + "의심 우선"으로 라벨 오류 사냥
7. COCO / YOLO 익스포트. Colab은 `승인 학습 데이터.zip → 노트북 → autolabel-model.zip 검증·적용` 순서

화면 위 **"지금 할 일"** 배너가 단계마다 다음 수를 알려주므로 순서를 외울 필요는 없다.

```bash
./test.sh      # 백엔드 회귀 88개 (모델 없이) — 코드를 고쳤으면 항상 실행
./test-e2e.sh  # 프론트 회귀 49개 (unit 14 + Playwright 35, ~1분) — 격리 DB 자동 기동
```

### 문맥 심판 (VLM) — 이 도구의 차별점

외형만으로 판정할 수 없는 라벨용이다. "사고에 연루된 차량만" 같은 기준은 검출 모델이 못 푼다.
**판정 기준을 글로 쓰면** VLM이 박스마다 부합 ✓ / 위반 ✗ / 불확실 ? 와 근거를 달아주고,
사람은 위반·불확실만 확인한다 — 리뷰가 전수 판독에서 예외 확인으로 바뀐다.

실제 판정 출력:

> ✗ **위반** (`dog`, conf 0.40) — "빨간 박스 안 주 객체가 개가 아니라 세로 나무 판자(울타리·상자 형태) 구조물이라 dog 라벨과 부합하지 않는다"

- **제공자는 플러그인** — Claude API(빠름, 종량 과금) / **Claude Code CLI 헤드리스(구독에 포함, 추가 비용 없음 — API 키 없이 쓰는 기본 경로)** / 로컬 Ollama. 셋 다 없으면 이 기능만 비활성되고 나머지는 정상 동작
- **재실행이 공짜** — 기준 해시 + 박스 스냅샷을 키로 캐시. 고친 박스만 다시 묻는다
- 판정은 병렬 (기본 3워커, `AUTOLABEL_VLM_WORKERS` — Ollama는 1). 한 변 24px 미만 박스는 호출 없이 "불확실·직접 확인"으로 확정해 시간·비용 절감

<details>
<summary><b>기능 전체 목록</b></summary>

<br>

**라벨링**
- 텍스트 프롬프트 배치 오토라벨 (클래스별 프롬프트·임계값 분리)
- **누락 최소화 프로필** — 전용 모델 후보를 conf 0.10+TTA로 넓게 뽑아 회수율 우선. 자동 승인 임계값과 분리되어 사람 검수 전용으로 동작
- 오토라벨 재실행은 낡은 모델 초안만 교체하고 사람이 고친 라벨을 보존. 같은 클래스 중복 예측은 자동 억제
- 예시 박스 1개 → 유사 객체 전부 (PerSAM 방식 특징 매칭, 학습 불필요)
- SAM 클릭 → 마스크 (클릭=새 객체, Shift=정제, 우클릭=제외)
- 박스 드래그·이동·리사이즈, 휠 줌 / Alt 팬
- **비디오 임포트** — mp4/mov를 올리면 프레임 추출(간격 선택) + SAM 3 메모리 전파 트래킹으로 프레임별 초안 라벨 자동 생성. 같은 객체는 `meta.track_id`로 연결. 영상은 라벨 비용이 "전 프레임 그리기"에서 "검수"로 줄어든다
- 타일링 추론 — 고해상도·작은 객체를 나눠 보고 NMS로 병합

**리뷰**
- 썸네일 리스트 + 상태·라벨수·신뢰도·QA 점수·심판 위반 수
- 필터 6종(전체·리뷰 대기·승인·미라벨·거부·**심판 ✗**) · **불확실 우선** · **의심 우선** 정렬 — `←→` 이동도 이 순서를 따름
- `A`/`X` 승인·거부 후 자동 다음, 마지막 장에서는 앞쪽 리뷰 대기로 순환, `1~9` 클래스 재할당
- **`Cmd+Z`가 이미지를 건너서도 되돌린다** — 오승인도 취소된다. 그 이미지로 자동 복귀 (100단계)
- 우측 어노테이션 패널 — 선택·클래스 변경·삭제, 출처 표시(🤖 모델 / ✍️ 사람 / ▦ 마스크), 심판 판정 칩
- **이미지 목록 상시 노출** — 설정·도구(클래스·임포트·익스포트)는 접히고, 매번 쓰는 썸네일 목록이 사이드바를 차지한다
- 넘길 때 목록이 따라오고 `26 / 143` 위치 표시 · **Shift/⌘+클릭 다중 선택 → 일괄 승인·거부**
- 서버 썸네일(디스크 캐시) — 목록이 원본을 받지 않는다 (**전송량 −97.8%**)
- **창 렌더링** — 보이는 구간만 DOM에 올린다 (310장에서 노드 2364 → 321)
- 박스 선택 중 화살표로 **1px 미세조정**(Shift 10px), `Esc` 선택 해제
- 거부 이미지는 **익스포트에서 제외**되고 `거부` 필터로 되살릴 수 있다
- 배율 표시 + 맞춤 버튼, `+`/`−`/`0` · 캔버스가 창 크기를 따라간다
- **2초 자동 저장 + 실패 시 경고·자동 재시도** — 저장이 안 되면 헤더에 계속 표시하고 5초마다 재시도, 서버가 돌아오면 스스로 복구. 미저장 상태로 창을 닫으면 경고
- 드래그앤드롭 업로드 · "지금 할 일" 단계 안내 배너

**콜드스타트 (제로샷이 약할 때)**
- **SAM 3 + Grounding DINO 교차 초안** — 처음 3장에서 두 엔진의 합의·단독 후보를 함께 보여주고, 합의가 낮으면 느린 이중 추론을 자동 축소
- **검수 기반 클래스 라우팅** — 사람이 승인한 정답과 두 엔진의 원본 후보를 비교해 오검출 삭제 1, 누락 보정 3의 검수 비용으로 채점. 클래스마다 SAM 3 / Grounding DINO / 둘 함께 중 낮은 작업량을 선택
- **프롬프트 실험** — 후보 표현을 표본 5장에 돌려 검출 장수·확신도·장당 박스로 비교하고, 이긴 것을 클릭 한 번에 적용
- **배치 결과 진단** — 검출률이 낮으면 결과만 던지지 않고 다음 수를 지정한다 (프롬프트 실험 / 직접 라벨 후 학습). 대상이 없는 이미지가 섞인 경우까지 감안해 단정하지 않는다

**자동화 (리뷰 부하 감소)**
- **안전한 자동 승인(TBAL)** — 독립 홀드아웃을 통과한 전용 모델이 예측했고, QA val에서 클래스별 정밀도 95%를 확인한 박스만 승인. 범용 모델·미검증 모델·빈 초안은 confidence가 높아도 자동 승인하지 않으며 실행 전 대상 수와 차단 이유를 미리 보여준다
- **통계적 배치 검수** — 전수 대신 필요한 표본만 검사해 배치를 승인 (로트가 작으면 전수 검사라고 정직하게 말한다)
- **누락 찾기** — 모델이 찾았는데 라벨에 없는 박스를 점선으로 제안, 클릭 한 번에 라벨로 승격
- **다음 라벨 추천** — 모델이 헷갈리는 이미지를 우선 제시 (능동학습, 라벨 예산 최적화)
- **학습 이력** — 라운드별 mAP 막대 + 이전 모델로 롤백

**계층 라벨 (객체 안의 객체)**
- 클래스를 `person.head`처럼 쓰면 **part 캐스케이드** 작동 — 부모를 먼저 찾고 그 crop 안에서만 부위를 검출
- 사람 부위는 키포인트 전문 모델 경로 (머리·팔·다리·몸통), 일반 객체는 crop 확대 후 grounding
- part는 `parent_annotation_id`로 부모와 연결되어 저장

**학습 & 품질**
- 승인 8장부터 자동 파인튜닝, 이후 5장마다 재학습 (별도 프로세스 — 서버 재시작에도 생존)
- **상시 학습센터**: 설정을 접어도 접근 가능. 시작 전 승인 수·예상 train/val/test·추천 모델·다음 자동 조건, 실행 중 5단계·실제 epoch·진행률·경과·ETA, 완료 후 새 모델 적용/기존 모델 유지와 핵심 지표를 한 흐름으로 표시
- **데이터 규모별 모델 자동 승급**: 800장 미만 yolo11n · 3,000장 미만 yolo11s · 그 이상 yolo11m
- **배포 체크포인트 이중 평가**: mAP용 `best.pt`와 마지막 수렴점 `last.pt`의 운영 F1을 같은 val에서 비교하고, 실제 추론에 나은 쪽을 승격
- **모델별 confidence 보정**: val의 F1-confidence 곡선으로 클래스별 운영 임계값을 기록해 “mAP는 높은데 기본 conf에서 0건”인 모델을 방지
- **☁ Colab 학습**: 승인 이미지만 고정 train/val/test로 묶은 zip + 노트북을 받아 GPU 학습 → 성능표와 가중치를 담은 `autolabel-model.zip`을 검증 후 적용
- 영상·연속 촬영 그룹을 한 분할에 고정해 평가 누출을 막고, challenger와 현재 champion을 같은 val에서 다시 비교
- 클래스별 추천 임계값 (정밀도 95% 달성 최소 confidence) · **원클릭 적용**
- 라벨 의심 랭킹 (모델 vs 라벨 불일치, 확신도 가중)
- COCO / YOLO 익스포트, 전용 모델 `.pt` 다운로드, 라벨 출처 메타데이터(모델명·프롬프트·임계값) 기록

끝난 줄 알고 넘기면 그 오염은 학습셋까지 조용히 흘러간다. 그래서 검증은 3단이다.

<details>
<summary><b>설계 원칙 (전부 실사고에서 나온 것)</b></summary>

<br>

- **마스크 원본 크기 복원은 브라우저 JS에서** — ONNX 그래프에 맡기면 세로 이미지에서 crop 치수가 뒤집힌다 (실측 IoU 0.18)
- **이미지 전환 시 임베딩 무효화** — 순번 검사 + 크기 검증으로 이전 이미지 임베딩 사용 레이스 차단
- **학습은 인프로세스 금지** — 서브프로세스 + 상태 파일. `--reload`가 학습 스레드를 죽인 사고에서 나온 규칙
- **champion/challenger + 품질 하한선(mAP50 ≥ 0.3)** — 재학습이 항상 개선은 아니다. 콜드스타트 쓰레기 모델의 승격 차단
- **AP와 운영 가능성은 따로 본다** — AP는 confidence 순위만 좋아도 높다. 실제로
  epoch 2 `best.pt`가 mAP50 0.865인데 confidence가 전부 0.01대라 기본 설정에서
  검출 0건이었다. `best`/`last`의 val 운영 F1을 함께 비교하고 모델별 임계값을 저장한다
- **온톨로지 = config** — 클래스명과 검출 프롬프트를 분리 (도메인 전환이 설정 변경으로 끝난다)
- **"정탐이냐"와 "새 객체냐"는 다른 질문** — mAP 관례의 IoU 0.5를 누락 판정에 쓰면
  IoU 0.4로 겹친 같은 객체가 '누락'으로 나가 중복 라벨이 박힌다. 신규 판정은
  IoU + 양방향 포함률로, 훨씬 엄격하게
- **조용한 skip 금지** — 파일이 없으면 건너뛰지 말고 세어서 노출한다
  (`X-Images-Missing`). 빈 익스포트가 성공으로 보이던 사고에서 나온 규칙
- **파괴적 UPDATE 전에 대상 확인** — 없는 id로 롤백하면 전부 비활성화만 되고
  아무것도 활성화되지 않아 전용 모델이 사라졌다
- **검증은 실내용을 봐야 한다** — zip의 `PK` 두 바이트를 확인하는 검사가
  data.yaml 한 장짜리 빈 zip을 통과시켰다. 개수를 세라
- **비동기 핫키는 ref + 큐로** — 승인이 클로저의 `current`를 읽어, 연타하면
  같은 이미지를 두 번 처리하고 나머지를 건너뛰었다 (실측 5연타 → 2장).
  최신 값은 ref로 읽고 작업은 프라미스 체인으로 직렬화한다
- **되돌리기 이력은 이미지가 아니라 프로젝트 단위** — 이미지별로 두면 넘기는
  순간 사라져서, 되돌릴 수 없는 파괴적 동작(오승인)이 생긴다
- **실패한 저장은 반드시 화면에 남긴다** — 자동 저장에 catch가 없어 서버가
  죽으면 콘솔에만 남고 라벨러는 계속 작업하다 전부 잃었다. 경고는 지워지지
  않는 배지로, 복구는 자동 재시도로
- **추론 응답은 요청 시점 이미지에만 반영** — 단건 오토라벨·예시 매칭이 수 초
  걸리는 동안 `→`로 넘어가면, 늦게 온 응답이 지금 이미지의 라벨을 통째로
  교체하고 자동저장이 그걸 서버에 박았다. 이미지가 바뀌었으면 버리고 알린다
- **후보 생성 임계값과 자동 승인 임계값은 다른 결정** — 초안은 누락을 줄이기
  위해 낮게 뽑을 수 있지만, 그 값을 승인 기준으로 쓰면 오라벨이 통과한다.
  누락 최소화는 명시적 프로필로 격리하고 승인 정책은 그대로 둔다
- **저장 완료가 dirty를 지우는 건 저장한 스냅샷이 최신일 때만** — 요청 비행
  중의 편집이 완료 순간 dirty와 함께 덮여, "저장됨"을 보고 닫은 탭에서
  마지막 편집이 사라졌다
- **공유 모델 상태는 set_image→predict를 원자화** — 배치 스레드와 `/embed`가
  전역 SAM predictor를 공유한다. torch가 GIL을 놓는 사이 끼어들면 A의 박스가
  B의 특징맵으로 디코딩되고, 오염된 임베딩이 해시 키로 캐시에 눌러앉는다
- **val/test 하한은 train 몫(절반)을 예약한 예산 안에서만** — 승인 8장에서
  하한 30이 전량을 val로 소진해 train 0장, 배정은 DB에 고착 — 이후 학습이
  영영 실패했다
- **삭제는 우리가 만든 파일만** — 연결 임포트 이미지의 실제 파일은 사용자
  원본이다. 이미지 삭제가 그걸 unlink해 도구 밖 데이터가 비가역 유실됐다
- **배치 오토라벨 기본 대상은 리뷰 전 이미지만** — 승인 이미지를 다시 돌리면
  검토된 라벨이 무검토 검출로 바뀌는데 status는 approved로 남아, 오염이
  학습셋까지 조용히 흘러갔다
- **온톨로지에 없는 클래스는 0번으로 오라벨하지 말고 제외 + 카운트** — 클래스
  이름 변경 후 익스포트가 옛 라벨을 전부 class 0으로 내보냈다
  (`X-Annotations-Skipped`)
- **부분 실패도 세서 알린다** — 업로드가 손상 파일을 조용히 건너뛰고 200을
  주면 프론트는 "N장 완료"로 거짓 보고한다. `saved`/`failed`를 함께 반환
- **대용량 응답을 RAM에 조립하지 않는다** — export.zip을 BytesIO에 만들면
  메모리가 데이터셋 크기만큼 치솟는다. 디스크 임시파일 + 전송 후 삭제,
  이미지 항목은 STORED (이미 압축본)
- **파생 상태는 원본에 동기화** — 온톨로지 에디터의 로컬 스냅샷이 밖에서 온
  갱신(임계값 적용·프롬프트 실험)을 모른 채 저장하면 그 변경을 조용히 되돌린다
- **유료 결과의 캐시는 "무엇이 판정됐나"를 키로** — VLM 판정 캐시는 기준 해시
  + 박스 스냅샷으로 잡고, 일시 장애(429·네트워크)는 error 플래그로 캐시에서
  제외한다. 안 그러면 장애 한 번이 영구 unsure로 굳고, 박스를 고쳐도 낡은
  판정이 유효한 척한다
- **백그라운드가 쓴 값은 전체 교체에서 보존 병합** — 판정(meta.vlm)은 서버가
  채우는데 클라이언트 사본에는 없다. 저장(DELETE+INSERT)이 그 사본을 그대로
  쓰면 유료 판정이 조용히 사라진다 — id 기준으로 보존 병합한다. 기록도
  통째 UPDATE 대신 json_patch로 키 하나만, 정체성(id+박스) 일치 조건과 함께
  (주의: json_patch는 RFC-7386 병합이라 이전 키 삭제는 명시적 null로)
- **SQLite 동시 쓰기는 3중으로 지킨다** — busy_timeout(경합 시 대기) + 짧은
  트랜잭션(느린 작업을 트랜잭션 안에 두지 않기 — 심판이 이미지 단위로 커밋해
  박스 판정 수십 초 동안 잠금을 쥐었다) + WAL은 기동 시 1회만(커넥션마다
  전환하면 전환 자체가 잠긴다). 셋 중 하나만 빠져도 "database is locked"
- **잡 상태는 저장소 하나** — 모듈 로컬 dict와 디스크 기록을 병행하면 반드시
  드리프트한다 (박스 진행률이 메모리에만 남아 재시작 복원에서 사라졌다).
  검사-등록 원자화(try_start)와 쓰기 스로틀도 그 한 곳에서
- **진행률은 사용자가 기다리는 최소 단위로** — 판정이 박스당 수십 초인데
  이미지 단위만 보여주면 30분째 멈춘 것과 구분이 안 된다 (실측: 죽었는지
  확인하러 옴)
- **"이미 거기 있음" 지름길은 비행 중 작업과 경합한다** — undo가 currentRef만
  믿고 이동을 생략했더니, 비행 중이던 열기의 fetch가 복구 직후 화면을 덮었다
  (DB엔 복구, 화면엔 빈 캔버스). 순번을 올리는 정식 경로를 항상 태울 것

</details>

## 스택

```
webapp/   Vite + React + react-konva
          └ SAM 디코더 ONNX(16.5MB)를 브라우저에서 실행 → 클릭당 서버비용 0

server/   FastAPI + SQLite
          ├ Grounding DINO   텍스트 → 박스
          ├ SAM 3 (선택)      텍스트 개념 → 인스턴스 분할 + 비디오 트래킹 (models/sam3.pt 있으면 자동)
          ├ SAM ViT-L        박스 → 마스크, 임베딩, 예시 매칭
          ├ YOLO11n          전용 모델 (자동 파인튜닝, MPS)
          └ 엔진 라우팅       활성 전용 모델 > SAM 3 > GDINO+SAM 폴백
```

## 한계

- 1인 로컬용 (SQLite, 단일 프로세스) — 멀티유저는 큐/DB 교체 필요
- 라벨 타입은 bbox + 마스크 + 계층(part). OBB·OCR·3D 미지원
  (비디오는 트래킹 임포트로 지원 — 프레임 단위 라벨로 변환)
- 예시 찾기는 미세 결함(35px급)에서 무력 — 특징맵 해상도 한계, 파인튜닝 루프가 담당
- part 캐스케이드는 사람이 작게 찍히면 키포인트를 못 잡아 일반 경로로 폴백
- 라벨 의심 랭킹은 모델이 약할 때 모델 오류가 섞인다 — "리뷰 가치 순"으로 읽을 것
- 문맥 심판은 구독(Claude Code) 경로에서 박스당 수 초 — 대량 배치는 시간이 든다 (병렬 3워커로 완화, 급하면 API 키)
- 전용 모델 YOLO 계열 = **AGPL-3.0** (개인/내부용 무방, 배포 시 RF-DETR 교체 지점 = `server/train_worker.py`)
